## What this project is about
> What is [RAG pipeline](https://code-with-amitk.github.io/Machine%20Learning/RAG/Introduction.html)
  
RAG pipeline fetches security logs data from sql DB, answer user Queries(using LLM), response of LLM is measured, diagnosed, and improved improving pipeline's performance.
